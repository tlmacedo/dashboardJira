# dashboardJira

O app novo (Kotlin + React) está em `app/` ([README](app/README.md)). O app Python antigo fica em `legacy/` e é apenas referência até a Fase 8.

- **`legacy/`**: painel web por Squad para Jira (backend FastAPI + front, app antigo). Comece por [`legacy/INICIO_RAPIDO.md`](legacy/INICIO_RAPIDO.md); manual em [`legacy/docs/manual/`](legacy/docs/manual/MANUAL_DO_USUARIO.md); procedimento para IA em [`legacy/INTEGRACAO_PARA_IA.md`](legacy/INTEGRACAO_PARA_IA.md).
- **`requirements.txt`**: dependências (`pip install -r requirements.txt`).
- **`docs/guia/`**: guia de dashboards nativos no Jira Data Center (JQL, gadgets, tempo em status).
- **`reports/`**: pesquisas que fundamentam o projeto; a principal é *Dashboard Jira gestão por squad*.
- **`legacy/docs/manual/`**: manual do usuário com capturas de tela (dados fictícios).
