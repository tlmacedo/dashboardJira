# dashboardJira

O app novo (Kotlin + React) está em `app/` ([README](app/README.md)). O app Python antigo (FastAPI) foi removido do repositório em 29/10/2026; o código, o manual e as capturas dele ficam preservados na tag `legacy-final` (`git show legacy-final:legacy/<arquivo>`).

- **`requirements.txt`**: dependências (`pip install -r requirements.txt`).
- **`docs/guia/`**: guia de dashboards nativos no Jira Data Center (JQL, gadgets, tempo em status).
- **`reports/`**: pesquisas que fundamentam o projeto; a principal é *Dashboard Jira gestão por squad*.
