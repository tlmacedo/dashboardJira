# dashboardJira

- **`app/`**: painel web por Squad para Jira (backend FastAPI + front). Comece por [`app/INICIO_RAPIDO.md`](app/INICIO_RAPIDO.md); manual em [`app/docs/manual/`](app/docs/manual/MANUAL_DO_USUARIO.md); procedimento para IA em [`app/INTEGRACAO_PARA_IA.md`](app/INTEGRACAO_PARA_IA.md).
- **`requirements.txt`**: dependências (`pip install -r requirements.txt`).
- **`docs/guia/`**: guia de dashboards nativos no Jira Data Center (JQL, gadgets, tempo em status).
- **`reports/`**: pesquisas que fundamentam o projeto; a principal é *Dashboard Jira gestão por squad*.
- **`app/docs/manual/`**: manual do usuário com capturas de tela (dados fictícios).
