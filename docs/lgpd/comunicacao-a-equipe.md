# Aviso à equipe sobre o Painel de Squads

Texto curto para a gestão enviar ao time antes do uso real do painel (por e-mail interno, ou como apoio numa reunião). A forma de aviso final é decisão do DPO (pergunta 5 do relatório). Linguagem simples, sem termos técnicos.

---

**O que é o painel.** É uma página interna que junta os dados das tasks do Jira: prazos, carga de trabalho, ausências e andamento das entregas. Serve para o time e a gestão se organizarem melhor.

**O que o painel mostra.** Quem tem tasks, quando elas vencem, quanto tempo ficam em cada etapa, quantas horas foram registradas e quem está ausente. Também mostra alterações de prazo, de responsável e de etiquetas de atraso, para alguém conferir.

**O que o painel não faz.**
- Nesta etapa ele **não escreve no Jira**: só lê.
- **Não cria ranking** com posições. As listas de nomes seguem ordem alfabética. Só a tela de padrões de fechamento (vista apenas pelo gerente) dá pontos a cada pessoa e compara com a média do time, como sinal para conferir, nunca como nota de desempenho.
- **Não tira conclusões**. Os avisos de alteração e de padrão de fechamento são **indício, não prova**: servem para uma pessoa conferir e conversar, nunca para julgar sozinhos.
- Não toma decisões sozinho. Quando sugere quem pode assumir uma task, a decisão é sempre de uma pessoa.
- Não guarda comentários, descrições, e-mail, foto nem nome completo.

**Quem vê o quê.**
- **Usuário:** vê os próprios dados.
- **Squad Leader:** vê os próprios dados e os do seu squad.
- **Coordenador:** vê todos os dados do time e as telas de conferência de alterações (Auditoria).
- **Gerente:** vê tudo o que o coordenador vê e, além disso, a tela de padrões de fechamento (Integridade) e o registro de quem consultou o painel.
As telas de conferência de alterações e de padrões só serão liberadas depois da autorização do encarregado de dados (DPO).

**Por quanto tempo os dados ficam.** Em geral 24 meses. Depois disso são apagados automaticamente. O prazo final é decidido pelo DPO e você será avisado se mudar.

**Tudo fica registrado.** Cada consulta ao painel fica registrada: quem consultou e quando. Isso protege você e a gestão.

**Como ver os seus dados.** No menu, abra **Meus dados**. Lá aparece o que o painel guarda sobre você e há um botão para baixar tudo em um arquivo.

**Para pedir correção ou eliminação**, fale com o encarregado de dados (DPO). Os dados vêm do Jira e são corrigidos lá.
